# aospbooks.github.io

Entry page for the [aospbooks](https://github.com/aospbooks) org, served at
<https://aospbooks.github.io/>. It links to the two books:

- [AOSP Internals](https://aospbooks.github.io/aosp-internal-book/) — deployed
  from [aosp-internal-book](https://github.com/aospbooks/aosp-internal-book)
- [Android Emulator Internals](https://aospbooks.github.io/android-emulator-internal-book/) —
  deployed from
  [android-emulator-internal-book](https://github.com/aospbooks/android-emulator-internal-book)

The page is a single static `index.html` with no build step; GitHub Pages serves
this repository's `main` branch directly.
